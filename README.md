# Enough: A Story With Snakes

A book about the things that actually run the world, co-authored by a human and an AI.

## Repository Structure

```
├── CLAUDE.md               # Instructions for Claude Code sessions
├── README.md               # This file
│
├── writing/                # The creative work
│   ├── CONTEXT.md          # Master context — project overview, outline, data
│   ├── DECISIONS.md        # Settled decisions — do not relitigate
│   ├── transcript_raw.md   # Raw chat transcript from brainstorming (reference)
│   ├── drafts/             # Section-by-section working drafts
│   └── notes/              # Endnotes, sources, book outline
│
├── research/               # Data verification and modeling (Python)
│   ├── data/               # Raw data files
│   └── notebooks/          # Jupyter notebooks — all analysis reproducible
│
└── site/                   # Astro + Tailwind — publishes writing to the web
```
