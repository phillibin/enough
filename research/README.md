# Research

Every number in the essay gets verified here. If it's not reproducible, it doesn't go in the piece.

## Structure
- `data/` — Raw data files (FRED downloads, BIS reports, BLS series, etc.)
- `notebooks/` — Jupyter notebooks for analysis and verification

## Key Data Points to Verify
- Derivatives notional value: $699T (BIS, 2024)
- Global GDP: ~$105T (World Bank)
- US labor share: 65.8% (Q1 1947) → 53.8% (Q3 2025)
- M2 velocity: peak 2.19 (1997) → 1.41 (late 2025)
- Money multiplier: 9.0 (2008) → 3.9 (2024)
- Financial sector profit share: 10% (1947) → ~40-50% (2000s-2010s)
- Finance sector GDP share: 2.8% (1950) → 8.3% (2006)
