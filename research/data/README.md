# research/data

Reference datasets bundled for prose_stats.py.

## brysbaert_concreteness.csv

Concreteness norms for 37,058 English single-word lemmas. Two columns:

```
word,concreteness
```

Concreteness is a 1–5 mean rating (1 = abstract, 5 = concrete) collected from
~4,000 raters via crowdsourcing.

**Citation.** Brysbaert, M., Warriner, A. B., & Kuperman, V. (2014).
*Concreteness ratings for 40 thousand generally known English word lemmas.*
Behavior Research Methods, 46(3), 904–911.

**License.** CC BY.

**Source.** Trimmed from the ArtsEngine mirror of the original supplementary
file (bigrams excluded to keep single-word lookup clean):
https://github.com/ArtsEngine/concreteness
